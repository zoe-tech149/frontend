# Tip Calculator

## Problem
Build a calculator that calculates the total bill given the bill amount and tip percentagein one click.

## Specifications
- Enter bill amount input
- Enter tip percentage
- Calculate the total bill
- Display the total bill with currency

## Concepts 
- Select HTML elements using `document.querySelector()`
- Read values from number inputs, `.value`
- Handle button clicks with `addEventListener`
- Calculate percentages using JavaScript `tip percentage/ bill amount * 100`
- Format numbers using `toFixed`
- Update page content using `innerText`
